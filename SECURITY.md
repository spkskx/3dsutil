# Security Policy

## Supported Versions

Security fixes are handled on the `main` branch. Use the latest released version or latest `main` when testing a fix.

## Reporting a Vulnerability

Please do not report security issues in public issues.

Use GitHub's private vulnerability reporting if it is available for this repository. If it is not available, contact the maintainer through the contact options listed on their GitHub profile and include:

- A short description of the issue.
- Steps to reproduce it.
- The affected command or workflow.
- Any relevant version, commit, operating system, or network details.

The maintainer will review the report, ask for clarification if needed, and coordinate a fix before public disclosure when appropriate.

## Scope

Examples of in-scope issues include unsafe archive extraction, path traversal, unintended file overwrite behavior, command execution, or leaking sensitive local information through errors.

Issues involving a local network, a modded 3DS, Homebrew Launcher, NetLoader, or ftpd may also depend on those projects. When appropriate, please report upstream issues to the affected project as well.
