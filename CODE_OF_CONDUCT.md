# Code of Conduct

This project is a small tool for the 3DS homebrew community. Keep discussions practical, respectful, and focused on helping people use or improve the project.

## Expected Behavior

- Be respectful of different experience levels.
- Give clear, constructive feedback.
- Stay on topic in issues, pull requests, and discussions.
- Assume good intent, but accept correction when something causes harm or confusion.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Posting private information without permission.
- Repeatedly derailing technical discussions.

## Reporting

If you see behavior that violates this code of conduct, contact the maintainer through GitHub by opening a private security advisory or by using the contact options listed on the maintainer profile.

Reports will be reviewed as privately as possible. Maintainers may remove comments, close issues, block users, or take other reasonable action to keep the project usable and welcoming.
